# FRONTLINE — Tactical Operations

A browser-based tactical shooter in the Counter-Strike mould: 5v5 defusal, free-for-all, 1v1 duels and a solo assault course.
Insurgents attack, the Task Force defends. Rendered with a bodycam look by default (switchable to a clean "tactical" style).

## Run it

```bash
npm install
npm start
```

Open http://localhost:3000, pick a callsign and hit **Quick play**.
Friends on your network can join the same room at `http://<your-ip>:3000/?room=<name>`.
Empty slots are filled with bots, so you can play solo right away.

`PORT=8080 npm start` changes the port; `BUY_TIME=5 npm start` shortens the buy phase for testing.

| Defusal | `de_cache` | Cache, compiled from its Hammer source: the real brushwork, stairs, slopes, terrain, ladders, bomb sites and buy zones, set in the Pripyat yard with the tower blocks, Ferris wheel and power plant on the horizon |
| Free-for-all | `de_cache` | Deathmatch across the whole of Cache |
| 1v1 Duel | `aim_rooftop` | A green-coated Seoul rooftop at golden hour: water tanks, AC units, onggi jars, a chain-link safety fence above the city |

The older hand-built maps (`de_trenches`, `dm_seoul`) are still in `shared/map.js` and can be selected by name.

### Compiling a Hammer map

```bash
node tools/vmf2map.mjs path/to/de_cache_d.vmf de_cache --title Cache   # collision + render geometry
node tools/radar.mjs de_cache                                          # CS-style overview for the radar
```

`vmf2map` turns every brush into a convex collision brush (with displacements as terrain prisms, player clips that stop players
but not bullets, and penetrable wood/crates/glass), writes the render mesh as a glTF with one mesh per surface family, and reads
spawns, buy zones, bomb sites, ladders and the sun from the entities. `radar` scans the floors the bots' nav graph can reach
and shades them by height.

## What's in the game

- **Match flow**: buy phase → 1:45 action phase → round end; first to 8 rounds, sides swap at halftime.
- **Free-for-all / duel**: kills earn money, bought guns stay with you, protected spawns, 3-second respawns.
- **Economy**: $800 start, per-weapon kill rewards, win/loss bonuses, plant reward.
- **Arsenal**: two guns, both fully animated — the M4 Carbine (rifle, $3100) and the P9 Pistol (everyone's sidearm) — plus the combat knife.
- **Utility**: Flashbang, Smoke Grenade, HE Grenade, Molotov, Sandbag Barricades (climb them and boot-stomp from above).
- **Movement**: Quake/Source-style — box-hull traces against convex brushes, sliding along walls, stepping up stairs, snapping down them, slopes, crouch-jumps and ladders.
- **Combat**: per-weapon spray patterns, movement inaccuracy, head/body/leg hitboxes, armour penetration, range falloff, wallbangs through wood, crates and glass, lag-compensated hit detection.
- **First person**: real animated arm rigs — authored draw / fire / reload animations for rifles and pistols, with every other weapon mounted on the same rigs.
- **Third person**: rigged operators with procedural walk / crouch / aim and two-bone IK keeping both hands on the weapon.
- **Rendering**: physical sky with image-based lighting, ambient occlusion, bloom, SMAA, filmic grade, procedural PBR textures with derived normal maps, and the bodycam lens (barrel distortion, sensor noise, REC burn-in).
- **Bots**: layered navigation over multi-level floors, auto-placed site entries and hold spots, buy logic, roles, rotations, plants/defuses, reaction time and recoil control.
- **Radar**: a pre-rendered overview of the reachable floors, shaded by height, with bomb sites and spawns marked.

## Architecture

```
shared/     constants (weapons, economy, recoil), maps, brush collision & physics & raycasts — used by both sides
  maps/        compiled map data (generated by tools/vmf2map.mjs)
server/     Node.js authoritative simulation @ 60 Hz, snapshots @ 30 Hz (match.js, bot.js, nav.js); big assets served brotli-compressed
tools/      vmf2map.mjs (Hammer .vmf → map data + glTF), radar.mjs (overview image)
client/     Three.js renderer + HTML/CSS HUD
  world.js     map builder: compiled-map materials or banded world-UV surfaces, per-theme sky/lighting/set dressing
  assets.js    glTF loading, rig measurement, static gun baking
  viewmodel.js first-person rigs + procedural weapons; soldier.js — third-person operators
  postfx.js    AO, bloom, SMAA, grade and the bodycam lens
  textures.js  procedural PBR textures (Korean signage uses Noto Sans KR)
```

## Assets

3D models live in `client/assets/models/` — see `CREDITS.txt` there for sources and licences.
They were converted from FBX/glTF and compressed (WebP textures, meshopt geometry) from ~200 MB of source files to ~9 MB.

`de_cache` is Cache (by FMPONE and Volcano, shipped in Counter-Strike by Valve), compiled here from its Hammer source.
The level design is theirs, so check the licensing before distributing this build publicly. Textures are procedural stand-ins.
